## Simplerp

lightweight Enterprise Resource Planning (ERP) web application designed to help businesses manage their core operational workflows from a single platform.

The application currently focuses on three key areas:
    - Inventory Management
    - Order Management
    - Shipment Management

At the moment, these workflows are managed manually through the SimpleRP interface. However, the system is designed with an API-driven architecture to support integration with e-commerce platforms and external services in the future.

This will allow SimpleRP to act as an operational backend between e-commerce platforms and internal business processes, enabling data such as products, orders, inventory, and shipments to be synchronized through APIs.
